BRAC web demo
=============

Upload this whole folder to the web host so the page is served at:
  https://analytitech.com/BRACYouth/

- index.html is one self-contained file. The only outside resource it loads is Google Fonts.
- Chat and Planning Center sync are simulated in the browser. No accounts, no server, no data stored anywhere.
- A robots meta tag (noindex, nofollow, noarchive) asks search engines not to index the page.
- To take it down, delete the BRACYouth folder from the host.
